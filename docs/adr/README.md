## ADR Process & Structure

Each record captures:
1. **Title**: Numbered sequence and concise description.
2. **Status**: `Proposed`, `Accepted`, `Rejected`, `Deprecating`, or `Superseded`.
3. **Context**: The forces, constraints, and business drivers.
4. **Decision**: The chosen technical approach.
5. **Consequences**: Both positive advantages and negative trade-offs.
